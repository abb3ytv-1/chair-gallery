# 🪑 Council Chair Vault

A playful React/Next.js web app built for **The Council**, a Twitch community — 
a fictional "governing chamber" where chairs get seated, ratified, and occasionally 
filed for "airborne events." Built as a fun way to gamify community inside jokes 
into something that actually functions like a real product.

## Features

- **Chair Chamber (Home)** — dashboard view with featured seat, live stats (motions, 
  seated count, "nods"), quorum tracker, and a recent activity log
- **Chair Archive** — searchable, filterable directory of all chairs by mood 
  (Founding, Chaotic, Cozy, Ceremonial, etc.)
- **Chair Detail View** — modal with chair art, mood tag, and lore/description
- **Saved / Favorites** — star chairs to save them, persisted per device
- **Profile** — sign-in and account creation flow to sync favorites across devices
- Light/dark mode toggle
- Bottom tab navigation (Home, Chairs, Saved, Profile) — built mobile-first
